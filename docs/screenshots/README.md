## Native workstation — version 0.5.0 synth sequencing

Rendered by the macOS processor test runner from the live-playback fix and synth-sequencer build. All six native test suites, both universal AU/standalone products, and both Audio Unit validators passed in [build run #33](https://github.com/robathanjames/beat-flip-au/actions/runs/37799895924). The image was visually reviewed: the independent drum/synth sequencers, note/chord/velocity/gate editor, and live keyboard fit within the expanded walnut cabinet.

## Web workstation — version 0.5.0 synth sequencing

Captured from the tested browser build at 1440 px and 430 px widths. Both layouts include independent drum/synth sequencers, chord/velocity/gate editing, immediately playable live keys and the FLIP engine. On narrow screens, each step row scrolls inside its panel. The actual-browser audio/layout regression checks passed for both sizes; these are real rendered interfaces, not mockups.
