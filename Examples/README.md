# Audio preview

`Beat-Flip-AB.wav` is included in the downloadable project package. It demonstrates four bars of a synthetic drum loop, followed by four bars processed by the engine, at 140 BPM.

The WAV is a generated preview, not an AU recording. It is omitted from Git history. Generate it from the source at any time using `Tools/RenderDemo.cpp` and the demo instructions in the main README.
